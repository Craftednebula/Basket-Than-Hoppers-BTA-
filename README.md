# Crafted's Basket Than Hoppers

completely server sided basket hopper mod

current features:
-taking from above containers.
-pushing to neighbours to the side and below.
-works with chest minecarts.
-when pushing into fuelled crafting stations from above, place items in the top slot.
-when pushing into fuelled crafting stations from the side, place items in fuel slot.
